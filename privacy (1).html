Privacy Policy

Last updated: July 2026

Pulse Core OS is a positioning-decision tool built and operated by a single independent rideshare driver in Vermont. This policy covers two separate things: this public website, and the private driver dashboard it links to.

This public website

This site does not collect any personal data from visitors. There are no accounts, no sign-up forms, no cookies, and no analytics or tracking scripts. The "example output" shown on the homepage is illustrative sample data, not a real person's driving activity.

The private driver dashboard

The dashboard is a separate, access-restricted application built on Google Apps Script and a private Google Sheet, used only by the operator. It stores:

  • Shift logs: dates, times, zones, earnings, tips, and mileage the operator enters themselves.
  • Driving history used to calibrate future recommendations.

This data is never displayed on the public website, never sold, and never shared with third parties for advertising or marketing purposes.

Third-party data sources

To generate recommendations, the private dashboard connects to:

  • Uber Marketplace Signals API — aggregate, non-personal ETA and demand-signal data, accessed via OAuth client-credentials authentication.
  • AviationStack — public flight arrival and delay data for Burlington International Airport (BTV).
  • Open-Meteo — public weather forecast data for the Burlington, VT area.
  • Google — hosts the private Sheet and Apps Script backend that store and process the operator's own data.

None of these integrations collect or transmit personal data belonging to rideshare passengers or the general public.

Credentials and security

API keys, client secrets, and access tokens are stored exclusively server-side, in Google Apps Script's Script Properties. They are never included in this website's code, never logged, and never displayed in any user interface.

Data retention

Shift and driving-history data is retained in the operator's private Google Sheet until the operator deletes it. This public website retains nothing, since it collects nothing.

Children's privacy

This website is not directed at children and does not knowingly collect information from anyone, regardless of age.

Changes to this policy

This policy may be updated as the system's data sources or architecture change. The date at the top of this page reflects the most recent revision.
